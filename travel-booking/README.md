# Ranjith Trails — Premium Travel

A responsive travel booking demo built with React, Vite, React Router, and Tailwind CSS. It uses curated mock travel packages and browser localStorage; no backend or payment processing is connected.

## Get started

```sh
npm install
npm run dev
```

## Features

- Home page with destination inspiration and featured travel packages.
- Searchable destination listing with category filters and price sorting.
- Package details with trip inclusions, duration, and ratings.
- Booking form with required-field/date validation and per-traveler price calculation.
- My Bookings page with localStorage persistence and booking removal.
- Responsive navigation and layouts for mobile and desktop.

## Other commands

```sh
npm run lint
npm run build
npm run preview
```

Bookings are stored in the current browser. The displayed prices are mock data in USD, and booking confirmation does not collect payment.
